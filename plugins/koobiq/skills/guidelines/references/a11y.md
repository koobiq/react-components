# Accessibility

Koobiq components build on React Aria, so keyboard support, focus
management and ARIA roles come for free — as long as the product gives them
names and doesn't rebuild them from divs. ESLint `jsx-a11y` (when the product
runs it) already covers raw DOM elements; focus on Koobiq components.

## Rules

**a11y/field-label** — every field (`Input`, `Textarea`, `InputNumber`,
`SearchInput`, `SelectNext`, `Autocomplete`, `TagInput`, `DatePicker`,
`DateInput`, `TimePicker`, `TimeRange`, `TreeSelect`, `RadioGroup`,
`CheckboxGroup`, `FileUpload`) has `label`, `aria-label` or `aria-labelledby`;
`Checkbox`, `Toggle` and `Radio` take their label as children. A placeholder
is not a label; `isLabelHidden` still needs `aria-label` · warning · both.

**a11y/icon-button-label** — `IconButton`, `Button onlyIcon` and icon-only
`Link` have `aria-label` / `aria-labelledby` describing the action
("Delete row", not "Trash") · warning · both.

**a11y/collection-name** — `Table`, `List`, `Menu`, `DropdownMenu`,
`TagGroup`, `Tree`, `Tabs` get `aria-label` / `aria-labelledby` when no
visible heading labels them · warning · agent.

**a11y/item-text-value** — collection items whose content is not plain text
set `textValue` (typeahead and screen readers use it) · warning · agent.

**a11y/dialog-name** — dialogs have an accessible name. Check the installed
`Modal`/`SidePanel`: if the header is not wired to `aria-labelledby`, pass
`slotProps={{ dialog: { 'aria-labelledby': titleId } }}` or `aria-label` ·
warning · agent.

**a11y/heading-semantics** — page and section titles are headings:
`<Typography as="h1" variant="title">`; don't pick heading variants for
non-headings · info (warning for the page title) · agent.

**a11y/clickable-non-interactive** — no `onClick` / `onPress` on `FlexBox`,
`Typography`, `div`, `span`; use `Button`, `Link` or a Koobiq collection item
· error · agent.

**a11y/landmarks** — navigation regions are landmarks with names:
`SideNavbar`/`TopNavbar` or `Sidebar as="nav"` with `aria-label`; toggles
expose `aria-expanded` · warning · agent.

**a11y/status-announcement** — content that appears dynamically (search
results count, empty states after filtering) is announced (`role="status"`)
· info · agent.

**a11y/img-alt** — informative images have `alt`; decorative ones `alt=""`
· error · agent · FP: projects running `jsx-a11y`.

**a11y/error-association** — validation errors go through `errorMessage` so
they are linked to the field · warning · agent.

**a11y/color-only** — status is not conveyed by color alone (add an icon or
text: `Badge`, `Alert` variants already do) · info · agent.
