# Internationalization

Koobiq components ship their own strings (en-US, ru-RU) and format numbers,
dates and calendars by the `Provider` locale. Product strings belong to the
product's i18n library; Koobiq only needs the locale.

## Rules

**i18n/provider-without-locale** — a localized app passes its current locale
to `<Provider locale={locale}>`, so built-in strings, calendars and number
formats match the UI language · info · script (with an i18n library such as
i18next, react-intl, next-intl or lingui in the dependencies).

**i18n/hardcoded-text** — in localized apps, user-facing props of Koobiq
components (`label`, `caption`, `placeholder`, `errorMessage`, `aria-label`,
`title`, toast and `EmptyState` texts, button text) go through the app's i18n
· info · script · FP: apps without an i18n library, tests, technical labels.

**i18n/date-value-type** — Koobiq date components take
`@internationalized/date` values (`CalendarDate`, `CalendarDateTime`,
`ZonedDateTime`, `Time`), not `Date` objects or strings · error · agent ·
fix: `parseDate('2026-01-15')`, `today(getLocalTimeZone())`.

**i18n/native-date-format** — dates shown to users go through
`@koobiq/date-formatter` with `@koobiq/internationalized-date-adapter` (or
`useDateFormatter` from the DS), not `toLocaleDateString`,
`Intl.DateTimeFormat`, moment/dayjs/date-fns patterns · info · script · FP:
serialization, logs.

```ts
import { DateFormatter } from '@koobiq/date-formatter';
import { InternationalizedDateAdapter } from '@koobiq/internationalized-date-adapter';

const adapter = new InternationalizedDateAdapter(locale);
const formatter = new DateFormatter(adapter, locale);

formatter.absoluteLongDate(adapter.parse('2026-02-03')!);
```

**i18n/validation-messages** — browser validation messages follow the
browser language, not `Provider locale`; pass `errorMessage` when the UI
language may differ · info · agent.

Other notes for reviewers: right-to-left layouts need logical CSS
properties (`margin-inline-start`, not `margin-left`) in product CSS; file
sizes can use `FileSizeFormatter` from `@koobiq/react-core` (documented
utility).
