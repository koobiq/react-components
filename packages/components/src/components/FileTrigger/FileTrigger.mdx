# FileTrigger

<Status variant="experimental" />

FileTrigger opens the system file dialog from any pressable component. It
renders no markup of its own, apart from a hidden file input.

For a complete file field with a list of uploaded files, validation and a drop
zone, use the [FileUpload](?path=/docs/components-fileupload--docs) component.

## Import

```tsx
import { FileTrigger } from '@koobiq/react-components';
```

## Trigger

Any pressable component works as a trigger without extra props: `Button`,
`IconButton`, `Link`. The trigger keeps its own `onPress` handler, the dialog
opens in addition to it.

<Story of={Stories.Triggers} />

<Alert status="warning">
  A child that is not pressable never opens the dialog — React Aria logs "A
  PressResponder was rendered without a pressable child" instead.
</Alert>

## Directories

With `acceptDirectory`, the dialog selects a whole directory. Every file keeps
its path in `webkitRelativePath`. Directory selection is a recent browser
feature: older browsers ignore `acceptDirectory` and open the regular file
dialog:

<Story of={Stories.Directory} />

## Camera

On mobile browsers, `defaultCamera` opens the camera instead of the file

## Opening programmatically

The ref points to the hidden file input, so the dialog can be opened from
anywhere with `ref.current.click()`, and the selection reset with
`ref.current.value = ''`:

## Accessibility

- The hidden input takes no `aria-*` attributes — label the trigger instead.
- The input has no `name` and is not submitted with a native form. Collect the
  files in `onSelect` and send them yourself.
