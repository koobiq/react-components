## Anatomy

- `TopNavbar` — the root navigation component. It arranges its content horizontally and provides keyboard navigation between items.
- `TopNavbar.Container` — a group of items on the start or end side of the navbar, selected with `placement`.
- `TopNavbar.AppItem` — the logo and the app name.
- `TopNavbar.Item` — a link or a button. Inside a `DropdownMenu`, it opens the menu, whose items are usually links too.
- `TopNavbar.Action` — the main action button.
- `TopNavbar.Divider` — a line between items.
