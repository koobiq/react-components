# Navbar

<Status variant="experimental" />

The main menu of the product: the logo, section links and actions.

## Import

```tsx
import { Navbar } from '@koobiq/react-components';
```

## Usage

<Story of={Stories.Base} />

## Props

<Props of={Stories.Base} />

## Subcomponents

- `Navbar.Header`, `Navbar.Body`, `Navbar.Footer` — groups of items at the top, in the middle and at the bottom. The body scrolls.
- `Navbar.AppItem` — the logo and the app name.
- `Navbar.Item` — a link or a button. Inside a `DropdownMenu`, it opens the menu.
- `Navbar.Action` — the main action button.
- `Navbar.Divider` — a line between items.

## Collapsing

The toggle button and <kbd>Ctrl</kbd>+<kbd>/</kbd> collapse the navbar. To control the state, pass `isCollapsed` and `onCollapse`.

<Story of={Stories.Controlled} />

## Expand over content

Make the navbar column as wide as the collapsed navbar, and it expands over the content.

<Story of={Stories.ExpandOverContent} />

## Long app name

A name that does not fit into one line takes two smaller lines. A longer one is cut off and shown in a tooltip.

<Story of={Stories.LongAppName} />

## Routing

Wrap the app in `RouterProvider`, and items with `href` navigate through your router, be it **Next.js** or **React Router**.
