# DescriptionList

<Status variant="experimental" />

DescriptionList displays term-description pairs, such as the properties of an
incident or an object.

## Import

```tsx
import { DescriptionList } from '@koobiq/react-components';
```

## Anatomy

```tsx
<DescriptionList>
  <DescriptionList.Group>
    <DescriptionList.Term />
    <DescriptionList.Description />
  </DescriptionList.Group>
</DescriptionList>
```

- `DescriptionList` — the list (`<dl>`). It is a grid of two columns:
  terms on the left, descriptions on the right.
- `DescriptionList.Group` — a term with its description (`<div>`). Put only
  groups inside the list: other children are not supported.
- `DescriptionList.Term` — a term (`<dt>`), e.g. a field name.
- `DescriptionList.Description` — a description (`<dd>`), e.g. a field value.

## Collections

DescriptionList supports static and dynamic collections.

In a static collection, pass the groups as children and set a unique `id` prop
for each group.

```tsx
<DescriptionList>
  <DescriptionList.Group id="status">
    <DescriptionList.Term>Status</DescriptionList.Term>
    <DescriptionList.Description>New</DescriptionList.Description>
  </DescriptionList.Group>
</DescriptionList>
```

In a dynamic collection, pass the data to the `items` prop and a function that
renders a group to the `children` prop. The group id is taken from the `id` or
`key` of the item, so you don't have to set it.

<Story of={Stories.DynamicCollection} />

The rendered groups are cached by item. If the function uses other values,
e.g. the locale, list them in the `dependencies` prop to re-render the groups
when the values change.

```tsx
<DescriptionList items={fields} dependencies={[locale]}>
  {(field) => (
    <DescriptionList.Group>
      <DescriptionList.Term>{field.label}</DescriptionList.Term>
      <DescriptionList.Description>
        {formatValue(field.value, locale)}
      </DescriptionList.Description>
    </DescriptionList.Group>
  )}
</DescriptionList>
```

## Orientation

By default, a description goes next to its term. Set the `orientation` prop to
`vertical` to put descriptions under the terms.

<Story of={Stories.Orientation} />

## Responsive orientation

The `orientation` prop accepts a value per breakpoint of the screen width.
Resize the window to see the layout change.

```tsx
<DescriptionList orientation={{ xs: 'vertical', m: 'horizontal' }} />
```

<Story of={Stories.ResponsiveOrientation} />

## Adaptive orientation

To switch the orientation based on the width of the list itself, measure the
list with [useElementSize](?path=/docs/hooks-useelementsize--docs) and pass
the result to the `orientation` prop. Drag the bottom right corner of the frame
to resize it.

<Story of={Stories.AdaptiveOrientation} />

## Columns

The `columns` prop sets the columns like CSS `grid-template-columns`. The term
takes the first column, the description takes the rest.

<Story of={Stories.Columns} />

## Alignment

Use the `alignItems` and `justifyItems` props to align terms and descriptions
vertically and horizontally. In the example, they are centered vertically.

<Story of={Stories.Alignment} />

## Long text

Text wraps inside its column: regular text by words, strings without spaces
(hashes, paths, URLs) by characters. The columns do not stretch.

<Story of={Stories.LongText} />

## Composition

A description can contain any content. For example, use `ClampedText` for a
long text and `ClampedList` for a long list.

<Story of={Stories.Composition} />

## Accessibility

- The list renders native `dl`, `dt` and `dd` elements, so screen readers
  announce terms together with their descriptions.
- `DescriptionList.Group` renders a `div`, which is valid inside `dl`.
