# Markdown

<Status variant="experimental" />

`Markdown` renders a Markdown string as HTML.

For the component to work, install the [`marked`](https://www.npmjs.com/package/marked) and
[`dompurify`](https://www.npmjs.com/package/dompurify) peer dependencies:

```bash
npm install marked dompurify
```

## Import

```tsx
import { Markdown } from '@koobiq/react-components';
```
